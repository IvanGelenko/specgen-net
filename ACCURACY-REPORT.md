# Проверка точности спецификаций — версия 1.3.5

Дата: 8 сентября 2026 года. Тестовый проект: `C:\проект\0873-000-ТХМ`.

Исправления внесены в исходники; 240 автоматизированных тестов прошли.
Release-сборка с библиотеками установленного AutoCAD Plant 3D 2026 завершилась
без ошибок и предупреждений. Инсталлер находится в `dist_installer`.

## Повторная проверка 1.3.5

- Воспроизведено завышение длины при суммировании 1000 гибов по 0,3 м:
  вместе с трубой 1 м получалось 301,1 м вместо 301,0 м. Сумма гибов переведена
  на десятичную арифметику; поиск проверяет совместимость только соседей,
  не копируя весь набор деталей для каждого гиба.
- Пустые поля Length и NumberInSet больше не блокируют чтение резервных значений.
  У PipeBend приоритет имеет CutLength — длина дуги; общее поле Length может
  содержать нулевую заглушку. Названия свойств читаются без учёта регистра.
  Неизвестное число болтов в BoltSet останавливает расчёт вместо предположения «1».
- Исправлено разделение одинаковых изделий из-за null/пустого DesignStd при
  одинаковом CompatibleStandard. Это уменьшило число групп труб с 78 до 74
  и сумму округлённых позиций с 1255,0 до 1254,8 м. Исходная длина осталась
  1251,564517432 м. Прежняя проверка не покрывала такое представление пустых полей.
- Кэш тегов различает источник идентификатора: локальную и проектную базу.
  После поиска строки в проектной базе её тег не подменяется строкой с тем же
  числовым идентификатором из другой базы.
- Чтение мешка свойств выделено в PartPropertyReader. Проверка на тестовой базе
  теперь проходит через этот же код, а не только через готовые PartRecord.
- Обычная сборка проекта берёт версию из VERSION вместо устаревшего значения
  1.1.22; явно переданная версия сборки по-прежнему имеет приоритет.

## Найденные ошибки

- **Пропуск 544 болтов.** В тестовой базе 82 комплекта BoltSet имеют пустую
  категорию. Категория теперь определяется также по конкретному классу детали.
  Весь набор из 379 комплектов даёт 2264 болта вместо 1720. Аналогично восстановлено
  распознавание заглушек Plug и Filter с пустой категорией; Support с категорией
  Default относится к опорам. Thread распознаётся как соединитель.
- **Неверная погонная масса 189 труб.** Теперь читается `LinearWeightUnit`.
  Значения `LB/FT` переводятся в кг/м независимо от `WeightUnit=KG`.
- **Перенос длины исключённых гибов.** Сворачивание выполняется после ограничения
  по чертежу, статусу, категории и линии. Длина не переносится в трубу другого
  диаметра, материала, толщины стенки или линии. Если подходящей трубы нет,
  гиб остаётся отдельной позицией. Граф соединений используется для поиска соседей.
- **Изменение результата при повторном расчёте.** Расчёт больше не удаляет значения
  из переданного словаря добавочных длин; диагностические счётчики очищаются.
- **Смешение идентификаторов чертежей.** Локальные номера получают пространство
  идентификаторов на весь проход, вместе с графом соединений и признаками
  принадлежности оборудованию. Исходные номера и чертежи сохраняются в журнале.
- **Арифметика количества и массы.** Длины суммируются десятичной арифметикой;
  округление вверх не добавляет лишнюю десятую метра из-за двоичной погрешности.
  Средняя масса учитывает длину труб и число болтов, а не число записей базы.
  Числа с десятичной запятой обрабатываются корректно. Нечисловые, бесконечные
  и дробные штучные количества останавливают формирование документа.
- **Объединение разных исполнений.** Ключ группировки учитывает толщину стенки,
  Schedule, давление, исполнение поверхности и стандарт. Различие только имени
  миникаталога Spec по-прежнему не разделяет идентичные изделия.
- **Ошибочное исключение крепежа арматуры.** Поиск ограничен чертежом, линией,
  миникаталогом и размером. Далёкая деталь не исключается через резервный поиск;
  неоднозначный резервный выбор оставляет детали в спецификации. Координаты
  приводятся к одной единице длины.
- **Выбор «Без статуса».** Теперь включает компоненты с null/пустым статусом.
- **Неполное чтение модели.** Ошибки чтения и отсутствующие чертежи прекращают
  генерацию; неполный результат не выдаётся как обычная спецификация. Повторный
  запуск заново читает проект: изменения базы без изменения времени DWG не
  скрываются старым кэшем.
- **Пропуск строки Word.** Некорректное число ячеек в области данных теперь
  вызывает ошибку до замены выходного файла. Запись также проверяет, что количество
  можно вывести без потери точности. Масса без достоверного значения отмечается
  в примечании и журнале.

и один раз округляет вверх до 0,1 м. Сверены наименования, линии и точная длина
каждой выходной позиции, а не только допустимый диапазон общей суммы. Расхождений
нет. Детали проверки сохранены в `artifacts/accuracy-0873/pipe-length-checks.json`.
У всех 660 труб Length и CutLength совпадают; пустых и неположительных длин нет.

## Границы подтверждённой точности

- Это сверка сохранённой базы и вычислительного ядра, а не проход команды через
  живой AutoCAD. Чтение DWG, соответствие базы геометрии, оборудование и фактическая
  топология требуют контрольного запуска в Plant 3D.
- В базе нет PipeBend. Исправления гибов проверены искусственными сценариями,
  включая фильтры, соединители и несовместимые трубы.
- У 56 труб отсутствует LinearWeight и равен нулю Weight. Из этих данных нельзя
  подтвердить массу. Плагин предупреждает о таких записях; он не восстанавливает
  недостающие каталожные значения. В смешанных группах средняя масса вычисляется
  только по записям с известной положительной массой и сопровождается примечанием.
- В тестовой базе нет RowId, привязанных к нескольким чертежам. Защита от
  совпадающих локальных номеров проверена отдельным тестом.
- Поиск ответного крепежа использует геометрию и признаки деталей, поэтому его
  результаты на реальных соединениях нужно сверить отдельно. Полная сверка
  количества выше выполнена с отключённым исключением ответного крепежа.
- Проверена сохранность содержимого Word; визуальная пагинация на пользовательском
  шаблоне в Microsoft Word отдельно не проверялась.

Абсолютная точность произвольного проекта не доказана. Подтверждены перечисленные
расчёты; найденные ошибки устранены, оставшиеся пробелы данных обозначены явно.

## Воспроизведение

Инструмент `tools/accuracy/export_project.py` создаёт снимок базы в отдельной папке,
не записывая в проект. `tools/accuracy/Accuracy.csproj` сравнивает его с результатами
ядра и проверяет обратное чтение Word. Данные текущего прогона:
`artifacts/accuracy-0873/source-summary.json` и `verification.json`.

```powershell
python tools/accuracy/export_project.py 'C:\проект\0873-000-ТХМ' 'C:\specgen\artifacts\accuracy-0873'
dotnet run --project tools/accuracy/Accuracy.csproj -- 'C:\specgen\artifacts\accuracy-0873\snapshot.json'
dotnet test test/PipingSpecPlugin.Tests/PipingSpecPlugin.Tests.csproj
```
